# GlassWeave examples

No sample application is implemented yet.

The first planned example is a UIKit app with a moving, app-owned background texture,
one custom refractive panel containing native controls, and an adjacent genuine Apple
glass control. It must demonstrate resize, input, accessibility preferences, and lifecycle
behavior. Add reference captures and a repeatable physical-device profiling route with
that implementation.

The executable work and acceptance gates are listed in [the backlog](../tasks/todo.md).
